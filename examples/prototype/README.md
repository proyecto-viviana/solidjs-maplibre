# Prototype Example App

This Vite app is the browser smoke target for the SolidJS MapLibre port. It is
not published with the package build.

## Modes

- Basic map
- Controls
- Marker popup
- GeoJSON source/layer
- Controlled map
- Feature picking
- Terrain and globe style controls
- Full demo

## Commands

- `pnpm run dev:prototype`
- `pnpm run typecheck:prototype`
- `pnpm run build:prototype`
